# Benchmark report (project-owned)

Generated by `benchmarks/run_benchmarks.py` against
`models/conversa-pt-fluent-v3.1`. The sets are small diagnostics inspired by
GPQA, HLE, GSM8K, HumanEval, SWE-bench and long-form generation; they are
**not** the official benchmarks and the numbers are not comparable to public
leaderboard scores.

| Category | Correct | Total | Accuracy |
|---|---:|---:|---:|
| science (GPQA-style) | 5 | 5 | 100% |
| hard reasoning (HLE-style) | 3 | 3 | 100% |
| math/word problems (GSM8K-style) | 5 | 5 | 100% |
| code generation (HumanEval-style) | 2 | 2 | 100% |
| patch (SWE-bench-style) | 1 | 1 | 100% |
| fluency checks (strict vs fluent) | 3 | 3 | 100% |
| long-form generation | 3 | 3 | 100% |

Additional metrics:

- PPM-C calibration probe: 2.2645 bits/byte, perplexity 4.8048 (small
  hand-written probe, not a representative held-out corpus).
- Peak child RSS measured by the runner: ~3.6 GB (loads the 543 MB artifact
  plus the diagnostic copy).
- Detailed answers, latencies and code are in `benchmark_report.json`.
- `fluency_rating_sheet.jsonl` and `long_form_rating_sheet.jsonl` are empty by
  design. Human ratings were not fabricated; fill them with real raters and use
  `scripts/evaluate_fluency_human.py score`.

The benchmark model is a temporary copy of v3.1 with
`benchmarks/data/science_facts.txt` and `benchmarks/data/long_form_facts.txt`
ingested. The source model directory is not modified by the runner.
